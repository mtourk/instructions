## Architecture Decisions Locked In

| Aspect | Decision | Why |
|--------|----------|-----|
| **Frontend framework** | None (vanilla JS + native APIs) | Minimal deps, fast, no build step needed for Pages |
| **Backend runtime** | Cloudflare Worker (Node.js-compatible) | Serverless, zero local footprint, free tier generous |
| **Database** | Cloudflare D1 (SQLite) | Free tier overkill for this use case, encrypted at rest, simple schema |
| **Voice discovery** | Gemini Live API | Real-time, conversational, transcripts included |
| **BMAD structuring** | Baked into Gemini system prompt | Conversation auto-aligns with factory's downstream parsing |
| **Secrets custody** | Cloudflare Worker environment only | Extends ADR-005 pattern; never reaches browser or local process |
| **GitHub auth** | Fine-grained PAT (new token) | Narrow scope (repo create + issues), separate from factory's daily creds |

## Step 1: Prepare Secrets

### 1a. GitHub Fine-Grained PAT

Go to GitHub Settings â†’ Developer settings â†’ Personal access tokens â†’ Fine-grained tokens

**Create token with:**
- Name: `cloudflare-repo-creation`
- Expiration: 90 days (or your preferred cadence)
- Permissions:
  - Repository: Administration (write) â€” allows creating repos
  - Repository: Contents (read) â€” allows reading repo (for seeding)
  - Repository: Issues (write) â€” allows filing issues
  - Account: Metadata (read) â€” allows checking username

Copy the token value (you'll need it in Step 2).

### 1b. Gemini API Key

1. Go to [Google AI Studio](https://ai.google.dev/aistudio)
2. Click "Get API key"
3. Create or select a project
4. Copy the API key (you'll need it in Step 2)

---

## Step 2: Set Up Cloudflare

### 2a. Create D1 Database

```bash
# Install wrangler (if not already installed)
npm install -g wrangler

# Authenticate to Cloudflare
wrangler login

# Create D1 database
cd factory/intake/worker
wrangler d1 create dark-factory-intake
```

**Save the `database_id`** shown in the output. You'll add it to `wrangler.toml` in the next step.

### 2b. Update wrangler.toml

Edit `factory/intake/worker/wrangler.toml` and fill in:

```toml
[[d1_databases]]
binding = "DB"
database_name = "dark-factory-intake"
database_id = "YOUR_DATABASE_ID_HERE"  # â† Paste from Step 2a

# For production environment
[env.production.d1_databases]
binding = "DB"
database_name = "dark-factory-intake"
database_id = "YOUR_DATABASE_ID_HERE"  # â† Same ID
```

### 2c. Add Secrets to Cloudflare

Via the Cloudflare dashboard:

1. Go to **Workers** â†’ **Secrets** (or find the settings for `dark-factory-intake` worker)
2. Click **Add secret**
3. Name: `GEMINI_API_KEY`
   Value: (paste your Gemini API key from 1b)
4. Click **Add secret** again
5. Name: `GITHUB_REPO_CREATE_TOKEN`
   Value: (paste your GitHub PAT from 1a)

**Note:** Don't put these in `wrangler.toml` â€” only as runtime secrets on Cloudflare.
